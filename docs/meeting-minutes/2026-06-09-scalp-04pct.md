# 회의록 — 0.4% 대칭 스캘프 전환 + 손절 본절 오분류 수정 (2026-06-09)

- **일자**: 2026-06-09
- **안건**: 봇 수익성 저조(순손실) 개선 + 손절 본절 오분류 버그 수정
- **절차**: 사용자 직접 지시(/trade-review 생략, 바로 구현) — 본 회의록이 의사결정 기록 대체

## 배경

- 실계좌 순손실 지속. TP 8%(@5x 레버리지 = BTC 1.6% 이동) 는 적중 ~40%로 목표까지 닿는 빈도 낮음.
- 손절(`SL`) 발생인데 청산 사유가 "본전" 으로 오표시되는 버그 확인.
  - 원인: `_sl_exit_reason` 미구현 — 가격 비교 방식이 노이즈로 오분류.
- 사용자 판단: 단타(scalping) 전략으로 좁혀 SL/TP를 증거금 2% (가격 0.4% @5x) 대칭으로 전환.

## 결정

1. **SL/TP = 증거금 2% (가격 0.4% @5x) 대칭**, R:R 1:1.
   - TP: 마진 +2% (가격 +0.4%) 에서 100% 전량 익절.
   - SL: 평단 기준 마진 −2% (가격 −0.4%) 에서 전량 손절.

2. **추매(물타기) 체결마다 평단 기준 SL·TP 재계산 + Binance 양쪽 재배치**.
   - 추매 후 평단가 변경 시 즉시 SL/TP 주문 취소 후 재발행.

3. **진입 물타기 간격을 0.4% SL 안쪽으로 축소** (cap 0.35%) — 3분할 추매가 SL에 막히기 전에 체결되도록.
   - floor: 0% / 0.1% / 0.2%, cap: 0% / 0.2% / 0.35%.

4. **분할 매도 폐기 유지** (이미 단일 TP). **min_sl 0.5% floor 제거** (0.0%).
   - 0.4% 이동폭에서 0.5% floor 는 SL을 역방향으로 밀어내 실질 SL을 확대하는 문제.

5. **청산 사유를 실현손익 부호(SL-vs-평단) 기준으로 분류** (`_sl_exit_reason`).
   - 실현손익 ≥ 0 → 본전/TP, < 0 → SL. 가격 비교 오분류 버그 수정.

| 항목 | 내용 |

| R:R | 1:1 (SL = TP = 가격 0.4%) |
