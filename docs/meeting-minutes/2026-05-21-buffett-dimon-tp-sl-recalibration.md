## 2. Buffett 입장

> "리스크는 자신이 뭘 하는지 모를 때 온다. 0% TP3 도달률이 그 증거다."

- **A 채택, B 최악, C 기각**
- B: TP1 0.6%→0.3% 단축은 노이즈에 다 잡혀 수수료 폭증. "자잘한 수입" 환상은 Berkshire 가 절대 안 사는 상품.
- C: BTC 단일자산 상관계수 1.0 → 분산 의미 없음.
- 수수료 1.35배: 사형선고. 회전율 절반으로.
- 승률 27.7% + R:R 2.87: 수학상 break-even (승률>25.8%) 이나 마진 0.4%에 불과. 표본 47개로는 통계적 환상 가능.
- 95% 풀베팅: 절대 금지. 청산 한 번이면 게임 끝.

**Buffett 처방**: threshold 0.55→0.70 / 0.70→0.80, 마진 캡 95%→35%, TP1 마진 3%→4% (청산 50%→40%), SL 잔고 -2%→-1.2%, 동시 1포지션 유지, 일일 max 2거래 제한.

## 3. Dimon 입장

> "Risk happens fast. 자잘한 수입은 자잘한 파산의 전조다."

- **A 채택, B 자살행위, C 분산 위장**
- B: TP3 도달 0% 인데 거리 더 좁히면 R:R 2.87이 1.5로 붕괴, catastrophic 노출 증폭.
- C: BTC 단일자산 멀티포지션 = 상관계수 1.0 = 분산이 아닌 **레버리지 위장**.
- SL 거리 분석: 5x × BTC 1% = 마진 5% ≈ 잔고 -2% 직격. SL이 1h ATR ~0.6% 의 1.7σ → **노이즈 손절 빈발**이 SL 60% 원인.
- 27.7% × 2.87 = 0.795 → break-even 미달, 수수료 차감 시 음수 EV 확정. Fortress 관점 **non-sustainable**.
- 시그널 진단: hit-rate 28% 자체가 random(50%) 대비 결함 + SL 거리 비대칭 둘 다 문제. TP1만 잡히고 TP3 0% = mean-reversion 장세에 trend 시스템 돌리는 셈.
- Flash crash -5% × 5x × 95% 풀베팅 = **잔고 -23.75% 단일 이벤트**. risk-of-ruin 이 아니라 ruin 자체.

**Dimon 처방**: threshold 0.55→0.68 / caution 0.80, 마진 캡 95%→40%, 동시 1개 유지, SL BTC 최소 0.3%→0.8% + 잔고 -1.5%, TP1 50%→40% / TP2 30%→40% 재분배.

### 핵심 변화 요약

1. **신호 품질 ↑** (0.55→0.68): 진입 빈도 47건/24일 → **약 25~30건/24일 예상** (-40~50%). 수수료 압박 직격 완화.
2. **마진 캡 ↓** (95%→40%): catastrophic flash crash 노출을 **잔고 -23.75% → -10%** 로 축소.
3. **SL 재조정** (잔고 -2% / BTC 0.3% → 잔고 -1.5% / BTC 0.5%): 노이즈 손절 빈도 감소, SL trade BTC 이동 분포(-1.04%) 대비 더 합리적 위치.
4. **TP1 거리 ↑ + 비중 ↓** (3%/50% → 4%/40%): 수수료 대비 R 확보, TP2 비중 ↑ 로 추세 캡처 시도.

### 사용자 호소("자잘한 수입") 대응 입장

실제 데이터(TP3 0%, SL 60%)는 "큰 거 가져가서 자잘 못 챙김" 이 아니라 **"신호 정확도가 random 수준이라 큰 거든 작은 거든 못 잡는 상태"** 임을 보여줌. → 빈도를 줄여 신호 품질을 살리는 게 우선.

## 6. 2차 라운드 — 사용자 안 (옵션 B 변종) 재토론

### 사용자가 결정한 방향 (변경 불가)
- **SL = 잔고 대비 -2% 손실** (현 유지)
- **TP1 = 마진 대비 +2%** (BTC 0.4% × 5x). 현 3% / BTC 0.6% 보다 짧게
- **TP1 청산 비중 ↑** (현 50% → 더 크게, "한 번에 들어가는 비중 더 크게")
- **TP3 = SL 과 충분히 떨어진 거리** (큰 추세 일부 끝까지)
- **TP2 = 그 사이 적절히**
- **단위 비대칭** 의도됨: "수익은 들어간 금액(마진) 대비, 손실은 총금액(잔고) 대비"

### Buffett mitigations
- TP1 청산 **75%** (70% 는 잔여 25% 가 TP3 0% 현실에 노출 / 80% 는 추세 trade 꼬리수익 깎음 — 75% 가 균형점)
- TP2 = 마진 **+5% (BTC 1.0%) × 비중 15%** (TP1 과 TP3 의 기하중간)
- TP3 = 마진 **+12% (BTC 2.4%) × 비중 10%** (SL 대비 6:1 거리, "잡히면 대박" 옵션)
- **마진 캡 95% → 80%** 절충 (3연패 시 잔고 -4.8% 회복 영역 유지)
- **신호 threshold +15~20% 상향** 필수 (TP1 짧으면 false signal 비용 폭증)
- **1일 거래 cap = 3건** (수수료 추가 압박 차단)
- **트레일링 유효 유지**: TP1 후 SL→본전, TP2 후 SL→TP1가 (75% 청산 구조와 완벽 호환)

### Dimon risk controls
- TP1 청산 **75%** (양 페르소나 일치)
- TP2 = 마진 **+5% × 15%** (양 페르소나 일치)
- TP3 = 마진 **+12% × 10%** (양 페르소나 일치)
- **R:R 분석**: TP1 마진 2% vs SL 잔고 2%. 마진 캡 95% 면 마진 2% ≈ 잔고 1.9% → **R:R 1:1.05 → 손익분기 승률 51.3%**. 현 27.7% 로는 EV 음수.
- **마진 캡 95% → 70%** 강력 권고 (사용자 95% 고수 시 notional cap = 잔고 × 3.5x + 일일 -6% 도달 시 24h 중단)
- **신호 threshold +15~20%**
- **시간 청산 48h → 24h** (회전 빨라진 만큼 stale position 빨리 정리)
- **Circuit breaker 3중**:
  - 진입 후 5분 내 BTC -1.5% → 즉시 시장가 청산
  - 일일 -6% → 24h 중단
  - 주간 -10% → 중단 + 재검토
